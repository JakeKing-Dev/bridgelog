# BridgeLog

A phone-first behavior log for special education, built by a paraprofessional.

**Live:** https://jakeking-dev.github.io/bridgelog/ · **App:** https://jakeking-dev.github.io/bridgelog/app/

Log tough moments (with what happened before and after), wins, IEP goal data and
restorative conversations on one timeline per student. See the month as a
calendar of school days, spot patterns for the team, and get a plain-English
summary for parent calls and IEP meetings.

- **Nothing leaves the device.** No accounts, no server. Data lives in the browser;
  back it up from the Data tab.
- **Records you can trust.** Entries lock at the end of the day they were entered.
  Mistakes can be voided that day with a reason; nothing is ever erased. Later
  notes are added and dated.
- **Patterns, not diagnoses.** It shows what the log suggests; a behavior's function
  is confirmed through an FBA by a qualified team.

It's a single HTML file with no build step: open `app/index.html` in a browser.
